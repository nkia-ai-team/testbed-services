# 사전 등록 템플릿 — 어떤 예측에도 적용하는 골격

2026-08-07 F10-P·F15-P 판독에서 드러난 절차 결함 셋을 반영해 만든 재사용 골격.
시나리오별 절차가 아니라 **예측을 측정 전에 못박는 일반 형식**이다.

> **왜 필요한가**: 이날 예측 둘 중 F10-P는 전반부만 맞고 F15-P는 반증됐다.
> 사전 등록이 없었으면 둘 다 "대체로 맞았다"로 흘러갔을 것이다.

---

## §0 예측 진술 (측정 전 작성)

```
예측:  <한 문장. "실패한다"가 아니라 "무엇 때문에 어떻게 되는가">
전제:  <이 예측이 서려면 참이어야 하는 것들>
```

**예측을 전반부/후반부로 나눌 수 있으면 나눠 적는다.**
F10-P는 "중단이 아니라 성공한다"(전반)와 "그 성공이 거짓 양성이다"(후반)로 갈렸고 **전반만 맞았다.**
나누지 않았으면 "대체로 맞았다"가 됐을 것이다.

## §1 지표 정의 확정 (측정 전 필수)

지표마다:
```
단위·범위      코드에서 확인 (검증식 인용)
계산식         무엇을 무엇으로 나누는가
정상 대역      과거 런 실측
BEFORE 가용성  런 시작 전 표본이 구조적으로 존재하는가
```

> **BEFORE가 구조적으로 없으면 배수 잣대를 등록하지 마라.**
> "표본 부족 시 안 쓴다"는 단서는 **항상 발동**해 오해만 부른다(F10-P의 `disk_io_util`이 그랬다).
> 대신 **주입 파라미터의 단조성** 같은 내부 대조를 쓴다.

## §2 판별식 — 세 규칙

### (a) 통계량 일치 ← *F15-P B-2 결함*
> **비교식의 통계량은 관측 대상의 통계량과 같아야 한다.**
> p95를 보면 p95 배수로, median을 보면 median 배수로.
>
> 실패 사례: p95 지표에 median 배수 기준을 걸어 **"평온"(배수 1.0)과 "183배 상승"이 동시에** 나왔다.

### (b) 스팬 스케일 ← *F10-P A-1 결함*
> **사다리·구간에 걸친 기준은 실제로 밟은 단 수에 스케일해야 한다.** 절대 임계 대신 **단당 증분**:
> ```
> 확정 : 단조 증가 AND (M_last − M_0) / (도달 단 수 − 1) >= <단당 임계>
> 없음 : 단당 증분 < <하한>
> ```
> 실패 사례: 3단 전제로 15pp를 걸었는데 2단만 밟아 10.5pp가 나왔다.
> **단당으로는 10.5pp인데 기준은 7.5pp였어야 했다.**
> **도달 단 수가 1이면 "적용 불가"로 쓰고 보조 잣대로 넘어간다.**

### (c) 잡음 대칭
> 여러 시점을 비교할 때 **각 시점의 성립 조건을 같은 형태로** 정의한다(예: 전부 "연속 N틱").
> 임계 성격이 다르면(백분율 대 개수) 민감도가 비대칭이 되어 선후 비교가 불공정해진다.

## §3 판정 규칙 — 배타성과 우선순위 ← *F15-P B-3 결함*

규칙을 나열한 뒤 반드시 검사한다:
```
[ ] 두 규칙이 동시에 참이 될 수 있는가?
[ ] 그렇다면 우선순위 또는 "층" 관계를 명시했는가?
```

동시 해당이 불가피하면 **층으로 적는다**:
```
직접 원인(무엇이 이 런을 끝냈나) : 규칙 X
근본 원인(고쳐도 성립하나)        : 규칙 Y
```
F15-P가 그랬다 — **게이지가 중단시켰고(직접), 강도 부족으로 성공은 못 섰다(근본).** 둘 다 참이다.

## §4 반증 조건 (필수)

```
내 예측이 틀렸다고 인정할 조건 : <구체적 관측>
그 경우의 후속 조치            : <무엇이 바뀌는가>
```

> **"제3의 결말"을 미리 넣어라.**
> 확인/반증 이분법으로 두면 어느 쪽도 아닌 결과에서 **기준을 만들어내게 된다.**
> F15-P에서 "게이지가 아니라 강도 부족"을 미리 넣어둔 것이 그 자리를 막았다 — 실제로 그 결말이 나왔다.

## §5 판정 불가 조건 (필수)

```
표본 부족   <신호별 최소 표본 / unusable 비율 상한>
정의 불가   <어느 값이 없으면 어느 판별식이 성립 안 하는가>
구간 미도달 <몇 단 이상 밟아야 유효한가>
```

> **기준이 안 맞으면 "판정 불가"가 정답이다. 억지로 확정을 만들지 않는다.**

## §6 편향 관리

```
[ ] 측정 전에 이미 본 데이터가 있는가? → 명시하고 기준 산정에서 격리한다
[ ] 기준을 정하려고 본 데이터가 예측과 관련 있는가? → 자진 신고한다
```
실제 사례: 임계 산정 중 자기 가설을 지지하는 런(`bb154509`)을 보게 됐고,
**그 런을 산정에서 제외하고 별도 관찰로만 기록**했다.

## §7 병기 필수 항목

```
런 id / t1·t2(UTC) / 도달 레벨 수와 구간 / 주입 파라미터 전문 /
주입 파라미터 변경 커밋 유무(있으면 과거 실측과 비교 불가) /
신호별 unusable 비율 / BEFORE 표본 크기 / 창 산정 근거(직전 런 t2)
```

## §8 두 창 규칙 (상시)

```
시간 경계  BEFORE는 직전 런 t2 이후. 시각은 UTC 통일 (런 디렉터리 파일 mtime은 KST다)
상태 경계  원인 판단은 evaluating 틱만. aborted·recovery·dirty는 결과이지 원인이 아니다
```
