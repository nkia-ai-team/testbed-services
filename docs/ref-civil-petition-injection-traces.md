# civil-petition 주입 수단별 119 흔적 표

설계 정본은 [SMS, NMS 전용 전통 3계층 테스트베드 설계](spec-testbed-vm-3tier.md)(이하 "설계") §6-7 이다. 이 문서는 그 표의 자리이고(설계 §6-6 "위치는 T4 에서 정함"), 칸과 줄과 채우는 규칙은 설계를 따른다. 실행기는 `scripts/scenarios/profiles/` 의 `vmlink_*`, `router_*`, `vmhost_*`, `vm_service`, `vmdb_*`, `vmload_north_south` 실행기이고 공통부는 `vm_executor_common.py` 다.

**지금 상태(2026-11-19 KST): 모든 칸이 실측 자리다.** 시험 실행(설계 §10 T4 "시험 실행")은 지휘 세션이 적용 에이전트로 한다. 이 표를 근거로 시나리오 후보를 만들지 않는다(설계 §7, 11-16 사용자 결정).

## 1. 채우는 법

1. 시험 실행 한 건마다 주입 시작 시각과 회복 끝 시각(평시 대역 복귀를 확인한 시각)을 적어 둔다.
2. 104 에서 저장소 `civil-petition/deploy` 를 작업 폴더로 삼아 아래를 돌린다. 읽기 전용이다(119 ClickHouse 는
   readonly, max_threads 2, max_execution_time 60, 모든 질의에 그 표의 분할 키 조건과 시각 범위).

   ```
   python3 tools/trace_table.py --inventory inventory/t.json \
     --start <주입 시작 ISO, 시간대 포함> --end <회복 끝> \
     --executor <실행기> --variant <변형> --run-id <시험 실행 id> \
     --words <시나리오 id>,<가드 작업 이름>,<가드 파일 이름> --json <결과 파일>
   ```

   평시 비교 창은 주입 창 앞 30분을 띄우고 같은 길이로 6개다(`--baseline-windows`, `--baseline-gap-min`).
3. 출력 첫 줄이 표 한 줄이다. 칸마다 대상, 계열이나 표, 바뀐 것, 첫 시각이 들어간다. 사람이 줄을 보고 "계기 흔적 판정"
   칸만 적어 아래 표의 그 줄을 바꾼다. 질의와 수치 전부(`--json`)는 T4 시험 실행 결과 파일에 남긴다.
4. 둘째 줄이 배관 흔적 판정(Q7 공통 낱말, Q7a, Q7b, Q7c, VM sudo 세션 닫힘 줄)과 운영자 경로다. Q7c 는 실행기 출발 주소(관리망 `host_addr`)의 새 연결만 본다. Q7c 의 연결 열쇠는 (대상, 출발 주소, 받는 포트, 출발 포트)다. 운영자 경로(설계 §6-2, Q35)는 운영자 단말 주소에서 온 로그인 수(주입 창 대 같은 길이 평시 창 최댓값, 합과 VM 별), 운영자 출발 연결 수(같은 비교), 경로 줄 넷(sshd 수락, 세션 열림, sudo `TTY=pts/N`, 세션 닫힘)의 119 도달 수로 낸다. 판정 기준은 없고 수만 낸다. 닫힘 줄은 운영자 sudo 명령 줄 수만큼 뺀 실행기 몫을 평시 창 최댓값과 견주고, 운영자 명령 줄 수는 따로 낸다(운영자 줄은 원인 흔적이다). 표에는 넣지 않는다(설계 §6-7 규칙). Q7d 는 관리 NIC 를
   받아들였으므로(v4 MNIC) SMS 지표 칸의 관리 NIC 줄을 보고 사람이 적는다.
5. 도구가 칸을 못 재면 "미측정, 이유" 를 넣는다. 빈칸은 없다. 기대(설계 §6-1 마지막 칸)를 실측 칸에 옮겨 적지 않는다.

도구가 하지 않는 것: 판정(계기 흔적이 섰나)과 줄 꼴의 뜻 풀이. 평시 창에 없던 꼴이 66 출발 줄에 주입 구간에만 있으면 원칙 8
위반 후보라 §6-2 의 66 거르기 보완 대상으로 적고, 보완 전에는 그 수단을 녹화에 쓰지 않는다(설계 §6-7 "66 출발 syslog").
도구 확인(2026-11-19 17:4x KST, 읽기만): T3 차례 4(라우터 ens19 90초 내림, 15:06 ~ 15:16 KST)를 평시 창 3개로 읽어 35초,
linkDown 과 linkUp trap, ens19 가용성 DOWN 과 UP, 서버 4대 UNKNOWN 과 UP, lldpd 의 "Network is down" 줄이 나왔다.
